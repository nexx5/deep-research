## characteristics

- 官方一手信息密度高：24 条断言中，成本（KC-17/23）、局限（KC-19/20）、架构（KC-03/04）、开放度（KC-06/15）均为官方自述但具体可核验，是付费组来源中信息完整度最高之一
- 两条成本证据链：API 按用量付费（$1-3 / $3-7 每任务）+ App 订阅分级（免费/Plus/Pro/Ultra 倍率）——付费组双轨定价结构
- 官方文档内部矛盾一处：结构化输出支持与否（发布文 vs API 文档 Limitations），提示能力状态随版本演进不稳定
- 基准自我宣称（HLE/DeepSearchQA/BrowseComp）为本文最有跨源对比价值的参数，且与 S006（Perplexity 官方 HLE 21.1%）形成直接竞品对照
- 局限披露领先同类官方来源：明确列出"不能做什么"（无自定义函数、无结构化输出、60 分钟上限、必须后台执行）
- 方法流派清晰：agentic 三步工作流 + thinking 模型 + 多步强化学习 + RAG 混合上下文——可归入"大厂 agentic 深度研究"流派
- 生态扩展信号：DeepSearchQA 基准开源 + 向 Search/NotebookLM/Finance/Vertex AI 扩散

## opposing_to

- 与"深度研究服务应开放透明（API/可审计/可自托管）"方向：本文显示 API 已开放但托管闭源（无自托管选项），且限制自定义函数、要求后台执行+存储，开放度有边界；开源框架主张可复现/自托管形成张力
- 与"基准分数应第三方独立验证"标准：46.4%/66.1%/59.2% 为厂商自报，社区可能以独立评测反驳；且官方用自建 DeepSearchQA 基准评价自家 agent，存在"用自家尺子量自己"的质疑空间
- 与"报告质量/引用忠实度"的社区实际体验：官方宣称"详细引用/减少幻觉"，但客户引述与基准均为自报；对立观点需社区口碑批次验证
- 与"免费可用"的感知：Deep Research 无计划用户也有额度（标准限额）但文档称"消耗较多用量"、高需求期可能受限（14620100 页提及），免费体验与营销感知可能有落差
- 官方内部对立：发布文"支持结构化输出（JSON schema）"与 API 文档"目前不支持结构化输出"直接冲突，能力状态对外口径不一致
