# 分析-A017：Gemini Fullstack LangGraph Quickstart 单源分析

## summary

本文是 Google 官方组织 google-gemini 开源的 fullstack 深度调研型 agent 示例仓库（Gemini Fullstack LangGraph Quickstart）。核心事实链：①官方开源姿态（GitHub API 独立确认，Apache-2.0、2025-05-22 创建、18294 stars）；②工程形态（LangGraph StateGraph 四节点：查询生成 gemini-2.0-flash → 并行 web_research（Google Search grounding）→ 反思 gemini-2.5-flash → 条件路由 finalize_answer gemini-2.5-pro，编译名 pro-search-agent）；③工作流范式（生成查询→并行检索→反思→迭代（默认最多 2 循环）→带引用合成）；④引用机制（grounding_metadata 长 URL 压缩为短 URL 插入 markdown 引用）；⑤开放度（全源码自托管，本地 dev / Docker / LangGraph Platform；生产形态依赖 Redis+Postgres+LangSmith）；⑥依赖边界（模型与检索均单一绑定 Google 供应商，仅需 GEMINI_API_KEY）。README 自述为 "research-augmented conversational AI" 示例，全文未出现 "Deep Research" 字样，也未声明与 Gemini Deep Research 付费服务的官方关系——这是"开源示例 vs 商业服务"对照的关键观察点。对本项目价值：大厂官方开源深度调研 agent 的工程实现形态一手证据，可与付费侧（S007）及开源复刻侧（S002/S011）构成三角对照。

## characteristics

- 大厂官方开源（google-gemini 组织）——开源组覆盖的关键证据，与社区复刻（S002/S011）形成对照
- 官方 API 全栈工程形态：Gemini 三模型分工 + Google Search grounding，无外部搜索供应商
- 双轨证据齐备：README 自述 + 源码独立验证，论证强度高
- 开放度高（Apache-2.0 全源码自托管），但生产形态依赖 LangGraph Platform 基础设施（Redis/Postgres/LangSmith）
- README 未声称"Deep Research"标签，定位为 "research-augmented conversational AI" 示例
- 成本透明性低：无运行成本/基准数据，仅能按 API 用量推断

## opposing_to

- 与"付费商业服务即开源版"的简单等同可能对立：本仓库 README 未声明与 Gemini Deep Research 付费产品的官方关系（未用该名称、homepage 指向 API 文档）；若后续判定"开源示例=商业服务"，需 S007 付费侧官方文档交叉验证，不能仅凭同属 Google 技术栈下结论
- 与"多供应商/可替换检索"流派可能对立：本仓库模型与检索均单一绑定 Google（仅 GEMINI_API_KEY），与 OpenDeepResearch（Tavily/多模型）、open-deep-research（Firecrawl 通道）等"自选供应商"架构构成流派分野——这是客观生态观察维度，非优劣评判
- 与"零依赖轻量部署"方案可能对立：本仓库生产形态要求 Redis+Postgres+LangSmith（LangGraph Platform 生态），与纯 Python 单文件/单体部署方案是不同工程取舍
