## summary

hyperresearch 是"开源 skill"产品形态的代表样本：以 pip 包形式安装进 Claude Code，生成 /hyperresearch Skill 与 18 个 step skill、16 个 subagent，用 16 步分层流水线完成从查询分解到对抗审查、引用验证、出货门禁的完整深研流程。其核心差异化主张有三：(1) 对抗性构建——4 个并行批评者 + 工具锁定（只允许 Read/Edit）的 patcher，物理上不能整篇重写报告，只能外科手术式修补；(2) 持久化 vault——Markdown 为真、SQLite 为缓存的知识库跨会话复用，配合来源质量评分（含撤稿检测）与独立性审计（同源转载只算一票）；(3) 开放获取恢复——通过 Unpaywall/Europe PMC 把付费墙论文转成合法 OA 全文再入库并四处披露替换。成本与基准维度：官方称在 DeepResearch-Bench RACE 榜领先（内部基准，第三方验证 pending）；基准 harness 记录 full tier 每查询约 1.5–2.5 小时、$60–120；v0.9.0 起产品内移除美元成本声明（订阅计费语境下 cost_usd 只是 API-equivalent 估值）。单源视角看，本文信息密度极高且自洽，但所有"领先/超越/高效"类陈述均为官方自述，独立验证缺位是理解该来源时必须保持的限定。

## characteristics

- 开源 skill 形态（pip + Claude Code Skill），MIT 许可
- 16 步分层流水线，三档 tier + 可调 gear
- 对抗性审查 + 工具锁定补丁（patch-only）
- 引用-句子绑定验证 + 撤稿阻断 + 防幻觉
- 持久化 Markdown+SQLite vault，跨会话知识复用
- 来源质量评分（OpenAlex/Semantic Scholar 引用权威 + PageRank + 撤稿）
- 独立性审计（同源转载加权）
- 开放获取恢复（Unpaywall/Europe PMC）与 4 处披露
- 学术 API 优先策略
- MCP 输出 + 本地 Web UI（不锁定在 Claude Code）
- 依赖 Anthropic 模型生态（订阅计费语境）
- 预算上限 + 崩溃恢复
- 对抗性输入防护（untrusted fence、XSS 修复）
- 官方声称基准领先但待第三方验证

## opposing_to

- 与"整篇重写/多轮重新生成"类深研方法论可能对立：本文以工具锁定（Read/Edit only）强制补丁式修改，明确排斥"重写草稿"路径
- 与"按 token 显式计费"类产品在成本披露上可能对立：本文在订阅计费语境下移除美元成本声明，改用 API-equiv 口径
- 与"一次性调研、报告即终产物"类工具对立：vault 复用是核心卖点，主张调研知识应沉淀复利
- 与"自带模型或厂商托管"类服务（OpenAI/Gemini Deep Research）对立：本文代表"用户自有 Claude Code 订阅 + 自托管"路线，并声称在基准上超越托管服务
- 与"同源转载可叠加共识"的朴素做法对立：独立性审计将 5 份转载压为 1 票
