## 摘要

GPT Researcher 官方文档（docs.gptr.dev，Docusaurus 站）+ 同作者 MCP server 仓库（assafelovic/gptr-mcp，361 stars，Python，MIT）合并采录。文档定义 GPT Researcher 为开源自主研究 agent：planner + execution agents 双角色架构，受 Plan-and-Solve 与 RAG 论文启发，单次任务聚合 20+ 网络来源；配置体系以环境变量为主（SMART_LLM/FAST_LLM/STRATEGIC_LLM/EMBEDDING 切换 15+ LLM provider、RETRIEVER 切换 11+ 检索器）；MCP 集成存在两个方向——（1）gptr-mcp 把深度研究封装为标准 MCP server 供 LLM 客户端调用（5 工具 + 1 资源 + 1 提示词，STDIO/SSE/Streamable HTTP 三传输），（2）GPT Researcher 自身可经 RETRIEVER=mcp 两阶段智能方法消费外部 MCP 工具（基于 langchain-mcp-adapters）。官方声称单次研究成本约 $0.1（introduction）与约 $0.01（FAQ，GPT-4 口径）存在文档间差异；官方警告非 GPT 模型可能遇到上下文限制错误。全部为官方声称，未经独立验证。
