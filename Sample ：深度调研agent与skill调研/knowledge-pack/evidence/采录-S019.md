# 采录-S019 hyperresearchbench

## 摘要

hyperresearchbench 是 hyperresearch（jordan-gibbs/hyperresearch）官方附属的 DeepResearch-Bench（DRB）复现 harness：在 Claude Code 上以 full tier（16 步对抗审查 pipeline）运行 hyperresearch，跑完 USTC DeepResearch-Bench 的 100 条 query，输出 JSONL 交给上游 RACE + FACT 评估器打分。README 公布官方分数：V8.3 stratified pilot（n=9）平均 overall 57.77，声称超过当时 DRB 公共排行榜第一名 xiaoyi 0.77 分。官方措辞承认该领先为 "benchmarked internally" 的分层试点投影，并声明第三方验证待进行。仓库 0 stars、1 fork、无后续提交，处于未采用状态。

## key_claims

- **statement**: hyperresearchbench 是 hyperresearch 的 DeepResearch-Bench 分数复现 harness，运行 100-query DRB benchmark，输出 JSONL 供上游 RACE + FACT 评估器使用
- **boundary**: 官方附属（作者 jordan-gibbs 同主仓库）；本身不提供新任务集、不提供新评估器，全部依赖上游 USTC DRB；利益相关声明必须保留
- **evidence**: README 首段 "Reproduction harness for hyperresearch's DeepResearch-Bench score. Runs the 100-query DRB benchmark against hyperresearch on Claude Code, full tier (16-step pipeline with adversarial review), Opus 4.7. Outputs a JSONL file ready for the upstream RACE + FACT evaluator."
- **characteristics**: 复现工具、官方附属、依赖上游评估器、Claude Code 载体

- **statement**: 任务集为上游 USTC DeepResearch-Bench（Ayanami0730/deep_research_bench）的 query.jsonl，共 100 个 PhD 级 prompt，英文 50 + 中文 50

### CL3（S019-3）评测指标为上游 DRB 的 RACE + FACT 双指标（Gemini LLM-as-judge）
- **statement**: 评分走上游 DRB 评估器：RACE 用 Gemini-2.5-Pro pairwise judge 评报告质量（comprehensiveness/insight/instruction-following/readability）；FACT 用 Gemini-2.5-Flash 评引用可信度（有效引用/总引用，web-scrape 引用 URL 验证）
- **boundary**: 评估器来自上游仓库（race.eval / fact.eval），由 grade.sh 调用；评估模型为 Gemini 系列，与被测的 Claude 模型不同供应商；需要 GEMINI_API_KEY
- **evidence**: grade.sh 注释 "Gemini-2.5-Pro for RACE, 2.5-Flash for FACT"；"RACE — report quality (comprehensiveness, insight, instruction-following, readability)"；"FACT — citation accuracy (effective citations / total citations)"；score 输出字段 overall/comprehensiveness/insight/instruction_following/readability
- **characteristics**: 双指标、LLM-as-judge、跨供应商评估、引用 URL 爬取验证

### CL4（S019-4）被测配置：hyperresearch full tier 16 步 pipeline，模型分层 Opus 4.7 / Sonnet 4.6 / Haiku 4.5
- **statement**: harness 在 Claude Code 上强制运行 hyperresearch full tier（16 步 pipeline 含对抗审查）；模型配比：Orchestrator/Critics(4×)/Synthesizer/Patcher+polish = Opus 4.7，loci-analysts/depth-investigators/draft sub-orchestrators/source-analyst = Sonnet 4.6，Fetchers = Haiku 4.5（crawl4ai 抓取，每波 8–12 并行）
- **boundary**: 描述的是该 harness 固定的被测配置；被测主体是 hyperresearch skill；prompt 显式 override pipeline_tier 为 full，防止短 query 被降级
- **evidence**: README Stack 表；harness.py RESEARCH_PROMPT "override `pipeline_tier` to `"full"` regardless of the query length — this is a benchmark run that requires the full pipeline"；harness.py docstring 模型分层说明
- **characteristics**: 16 步 pipeline、多模型分层、对抗审查、full tier 强制
