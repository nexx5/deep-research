# 采录-S010：DeepResearch Bench（USTC/Ayanami0730）

## 摘要

DeepResearch Bench 是中科大（USTC）团队（Mingxuan Du, Benfeng Xu, Chiwei Zhu, Xiaorui Wang, Zhendong Mao，Agent Research Lab / muset-ai 组织）于 2025-06-13 发布的深度研究 Agent（DRA）评测基准（arXiv 2506.11763，GitHub Apache-2.0，2026-08-04 时 805 stars / 85 forks）。基准由 100 个 PhD 级研究任务构成（50 中文 + 50 英文，22 个领域），任务需求分布基于 96,147 条匿名用户查询按 WebOrganizer taxonomy 统计而来。评测采用两套互补方法论：RACE（reference-based adaptive criteria，评估报告生成质量，四维度动态标准 + 参考报告对比 + 动态权重）与 FACT（信息检索与引用可信度，statement-URL 提取 + 去重 + web 抓取/LLM 判断验证 + 引用准确率/有效引用数指标）。评估器为 LLM-as-judge：RACE 用 GPT-5.5（2026-05-11 由 Gemini-2.5-Pro 切换，评估器选择经人类标注子集对齐度验证，人类 inter-annotator baseline 68.78%），FACT 用 GPT-5.4-mini。榜单托管于 HF Space muset-ai/DeepResearch-Bench-Leaderboard：legacy（Gemini-2.5 评估）榜单 45 条目、GPT-5.5 新榜单 10 条目，双榜单并列显示以保持评估器内可比性。提交官方榜单需 email 提供临时 GPT-5.5 key + 原始生成文章 + 可复现链接 + 模型元数据。团队后续发布 DRB II（arXiv 2601.08536，9,430 细粒度二元 rubrics）。

### A. 评测方法论（项目定义层）

**CL-1** 基准任务集构成：100 个 PhD 级研究任务，由 22 个领域的领域专家设计，50 中文 + 50 英文
- boundary: 任务数为仓库 README 与论文摘要一致陈述；"PhD 级/22 领域"为作者自述标准，未给出单任务复杂度量化
- evidence: README Overview 段 + arXiv 2506.11763 摘要原文
- characteristics: 双语任务集、专家构造、任务集规模

**CL-2** 任务需求分布依据：96,147 条匿名用户查询，按 WebOrganizer taxonomy 归类为 22 个主题域
- boundary: 仅陈述"分析/归类"，未公开查询样本或分布数据细节；查询来源为"web search-enabled LLM interactions"（未指明具体产品/时间段）
- evidence: README "Topic Distribution Analysis" 段
- characteristics: 数据驱动任务分布、真实世界需求对齐

**CL-3** RACE 评估方法：基于参考的适应性标准评估（Reference-based Adaptive Criteria-driven Evaluation），自动生成任务特定四维评估标准（Comprehensiveness、Insight/Depth、Instruction-Following、Readability），与高质量参考报告对比评分，采用任务特定动态权重
- boundary: README 仅给出流程概述；四维标准与动态权重的具体实现细节（prompt 模板、权重计算）在论文中，本条未深读论文正文
- evidence: README "RACE" 段 + 论文摘要 "reference-based method with adaptive criteria to assess the quality of generated research reports"
- characteristics: LLM-as-judge、报告质量评估、多维评分

**CL-4** FACT 评估方法：提取报告中的陈述-URL 对并去重，用 web 抓取 + LLM 判断验证引用是否真正支持陈述，输出两个指标——Citation Accuracy（正确支撑引用百分比）与 Effective Citations（每任务可验证支撑引用的平均数量）
- boundary: 与 RACE 互补（RACE 评报告质量、FACT 评信息检索/落地）；FACT 依赖 Jina API 做 web 抓取
- evidence: README "FACT" 段 + 论文摘要 "effective citation count and overall citation accuracy"
- characteristics: 引用可信度评估、自动验证流水线、检索能力度量

**CL-5** 评估器（LLM-as-judge）当前配置：RACE 用 GPT-5.5、FACT 用 GPT-5.4-mini；2026-05-11 之前 RACE 用 Gemini-2.5-Pro、FACT 用 Gemini-2.5-Flash
- boundary: 配置为 README News 与 HF Space 源码共同陈述；评估器切换原因是 Google 宣布 2026-06-17 弃用 Gemini-2.5-Pro
- evidence: README News (11 May 2026) + create_leaderboard.py 头部说明 + leaderboard_tab_gpt55.py "Eval Judge: GPT-5.5 (race) + GPT-5.4-mini (fact-check)"
- characteristics: LLM-as-judge 依赖、评估器版本敏感、闭源模型作裁判

**CL-6** 评估器选择过程：在人类标注子集（50 任务 × 4 目标 DRA = 200 文章）上测量三个候选前沿推理模型与人类判断的对齐度；人类 inter-annotator agreement baseline 为 68.78%，三候选超过 baseline 1.3–3 点；GPT-5.5 在 Overall、PAR、FAS 三个维度胜出，故被采纳
- boundary: 候选分数表仅给出 Overall/PAR/OPC/FAP/FAS 五列（GPT-5.5 71.82 / Gemini-3.1-Pro 70.58 / Claude-Opus-4-7 70.11）；未说明其余维度定义与显著性检验
- evidence: README News (11 May 2026) 表格
- characteristics: 人工对齐验证、评估器版本决策透明化

**CL-7** 榜单迁移机制：2026-05-11 公告——2026-05-31 前为双接受窗口（legacy Gemini-2.5-Pro 与新 GPT-5.5 并行接受、双榜单并列展示保证评估器内可比）；2026-06-01 起原论文结果自动用 GPT-5.5 重评迁移、Gemini-2.5-Pro 接受停止，仅维护 GPT-5.5 榜单；旧评估代码保留在 `Gemini-2.5` 分支
