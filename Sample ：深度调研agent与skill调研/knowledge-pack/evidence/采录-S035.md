# 采录-S035：浏览器代理流派评测标尺与竞品

## 摘要

本来源为多来源合并采录，覆盖浏览器代理（computer use）流派的"评测标尺"与"竞品"两个维度：

**评测标尺（论文一手定义，arXiv 摘要）**：
- OSWorld（arxiv 2404.07972，2024-04）：首个可扩展真实计算机环境基准，跨 Ubuntu/Windows/macOS，369 个开放任务，执行式评估脚本；人类 72.36%+ vs 最佳模型 12.24%，指出 GUI grounding 与 operational knowledge 是主要短板；代码/环境/基线开源。
- WebArena（arxiv 2307.13854，2023-07）：自托管四域真实网站环境（电商/社交论坛/协作软件开发/内容管理），长 horizon 任务，功能正确性评估；GPT-4 最佳 agent 14.41% vs 人类 78.24%；开源。
- WebVoyager（arxiv 2401.13919，2024-01，ACL 2024）：15 个真实流行网站任务，LMM（GPT-4V）自动评估协议与人类判断一致率 85.3%；WebVoyager 自身 59.1%。

**竞品（官方声称）**：
- Anthropic computer use（2024-10-22 官方公告）：Claude 3.5 Sonnet 为首个提供 computer use 公开测试版的前沿模型，API 让 Claude 看屏幕/移动光标/点击/输入文本；OSWorld screenshot-only 14.9%（next-best 7.8%），更多步数 22.0%；官方自述实验性、易错，滚动/拖拽/缩放有挑战；已开发滥用分类器；Anthropic API/Bedrock/Vertex AI 可用。
- Google Project Mariner（2024-12-11 Gemini 2.0 发布文 + 2025-05-20 I/O 更新文）：基于 Gemini 2.0 的早期研究原型，实验性 Chrome 扩展在浏览器内执行任务；WebVoyager 单 agent SOTA 83.5%；仅限活动标签页操作 + 敏感操作（购买）需用户确认；2025-05 升级为最多并行 10 个任务的 agent 系统，美国 Google AI Ultra 订阅者可获取，computer use 能力计划进入 Gemini API。

两个竞品与三基准之间构成"厂商在共同标尺上自报成绩"的对照关系（OSWorld 与 WebVoyager 被竞品引用为评估锚点）。

## characteristics

- 浏览器代理流派（computer use）评测标尺一手定义（OSWorld/WebArena/WebVoyager）
- 执行侧评估：真实计算机环境/真实网站/功能正确性（非简化的合成模拟器）
- 人类表现基线：OSWorld 72.36%+、WebArena 78.24%（论文发布时点）
- 模型成绩缺口：OSWorld 最佳 12.24%、WebArena GPT-4 14.41%（论文发布时点）
- 竞品厂商在共同标尺上自报成绩（Anthropic OSWorld 14.9%/22.0%、Google WebVoyager 83.5%）
- 竞品：Anthropic computer use（Claude 3.5 Sonnet，API/Bedrock/Vertex AI）
- 竞品：Google Project Mariner（Gemini 2.0 + Chrome 扩展，AI Ultra 订阅，agent 系统最多 10 任务并行）
- 安全设计：敏感操作确认、活动标签页限制、滥用分类器、prompt injection 对抗（官方声称）
- 开放程度差异：基准全部开源（os-world.github.io / webarena.dev / github WebVoyager）；竞品能力为闭源产品/实验性原型
- 来源性质分层：论文摘要（H 级事实）vs 厂商官方声称（M 级自报）
