## summary

dzhng/deep-research（README 自称 "Open Deep Research"，作者 David Zhang / Duet）是社区最热门的 OpenAI Deep Research 开源复刻之一（GitHub API 独立验证 19,474 stars，2025-02-04 创建，TypeScript，MIT/ISC 不一致，无正式 release）。其核心特征是**单 agent 递归深化**：一个 deepResearch 函数自调用完成"LLM 生成 SERP 查询 → Firecrawl 搜索抓取 → LLM 提取 learnings/方向 → depth>0 递归（depth-1、breadth 减半）→ LLM 汇总报告"的全过程。架构极简（官方声称 <500 LoC 目标），无独立规划器/记忆模块，learnings 与 visitedUrls 仅以数组随递归传递、不持久化；搜索与抓取全部委托 Firecrawl，自研部分仅为 LLM prompt 编排与流程控制。

关键观察（客观记录，不评判）：
1. 极简性是该项目的明确设计目标，官方声称代码量 <500 LoC；源码规模（deep-research.ts 10.1KB + 少量辅助文件）与目标一致，可独立复核。
2. 单 agent 递归是方法流派信号：同一循环内串行深化，与多 agent 编排（分工、并行子代理、独立规划器）形成鲜明对照。
3. 记忆为"纯上下文累积"：无记忆库/向量存储/持久化，跨会话知识复用能力为零（官方未声称具备）。
4. 检索与抓取完全依赖 Firecrawl 第三方服务（支持自托管 base URL），其成本/限流/能力边界直接影响本项目可用性。
5. 模型无关性较好：默认 o3-mini，可切本地 LLM、DeepSeek R1（Fireworks）、OpenRouter/Gemini 等 OpenAI 兼容 endpoint。
6. 仓库维护信号：最后推送 2026-04-11（约 4 个月前），无正式 release，93 open issues；README 仍是早期形态（未提及 agent 协作等新概念）。

## characteristics

- 单 agent 递归深化（方法流派核心特征）
- 极简实现（官方目标 <500 LoC，源码规模可复核）
- 搜索/抓取全部依赖 Firecrawl 第三方服务（支持自托管）
- 无独立规划器、无记忆库、无持久化（纯上下文 learnings 传递）
- 深度/广度参数化控制（depth/breadth）
- 模型可替换（o3-mini / 本地 / R1 / 自定义 endpoint）
- Markdown 报告 + Sources 引用列表
- Docker 与 HTTP API 支持
- MIT 许可证（package.json 标 ISC 不一致）
- 高社区热度（19,474 stars）但发布不活跃（无 release、最后推送 2026-04）

## opposing_to

- 与"多 agent 编排型"实现（OpenDeepResearch 等）：方向对立——本来源单循环递归、无分工与并行子代理；多 agent 方案以编排器+多个专职子代理为特征，可视为"深度 vs 广度/分工"的方法论两极
- 与"知识库/记忆型"方案：方向对立——本来源无任何跨会话记忆与知识复用，learnings 仅存活于单次运行；记忆增强型方案（向量库/知识图谱）在知识复用维度上相反
- 与"自研爬虫/检索器"方案：方向对立——本来源检索与抓取完全外包给 Firecrawl，自研能力边界在"prompt 编排"而非"检索实现"；自研检索方案在依赖控制与成本结构上不同
- 与"强调独立验证/评测数据"的来源：方向对立——本来源无任何评测基准、质量数据或第三方验证声明，全部为能力自述，可作为"无实证开源复刻"样本对比
