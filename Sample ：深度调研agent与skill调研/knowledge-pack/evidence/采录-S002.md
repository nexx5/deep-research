## 摘要

Open Deep Research（langchain-ai/open_deep_research）是 LangChain 团队基于 LangGraph 构建的开源深度调研 agent：采用 Scope→Research→Write 三阶段流程，以 supervisor 多 agent 架构并行调度多个研究子 agent，通过工具调用循环调用搜索/MCP 工具收集证据，最后一次性生成带来源引用的长格式研究报告。MIT 许可证、可自托管，默认 Tavily 搜索 + OpenAI 模型，在 Deep Research Bench 上官方自提交 RACE 0.4309-0.4943。

> ⚠️ 来源替换说明：任务指定的 https://github.com/OpenDeepResearch/OpenDeepResearch 为 404 死链（GitHub API 确认 OpenDeepResearch org 存在但 0 个公开仓库）。本条采录生态中承载 "Open Deep Research" 名称的最权威开源实现 langchain-ai/open_deep_research，其能力/架构可满足任务设定的 solution 节点证据需求。
