## summary

本来源是 GPT Researcher 官方文档（docs.gptr.dev）与官方 MCP server 仓库（assafelovic/gptr-mcp）的合并采录，属于"官方一手资料"类证据。核心主张：GPT Researcher 是开源自主研究 agent，以 planner + execution 双角色并行架构完成深度研究（单次聚合 20+ 来源），配置体系高度环境变量化（15+ LLM、11+ 检索器可切换），并在 MCP 生态中扮演双角色——对外以 gptr-mcp 提供深度研究工具，对内以 RETRIEVER=mcp 两阶段方法消费外部 MCP 工具。官方声称单次成本约 $0.1（Introduction）与约 $0.01（FAQ）口径不一致；官方承认非 GPT 模型存在已知限制。论证类型为官方宣称+接口文档陈述，成本与耗时数据未经独立验证，文档内部存在版本要求与工具命名的表述不一致。

## characteristics

- 官方一手资料（文档+仓库）
- 开源深度调研框架
- 环境变量配置体系
- MCP 双角色（提供 server + 消费 MCP）
- 多 LLM / 多检索器
- 成本口径冲突
- 官方披露的模型限制
- 文档内部不一致（版本/工具名）

## opposing_to

- 与"纯搜索 API 直用"类方案可能对立：本文主张深度研究 agent（自主探索、验证、聚合多源）优于直接返回原始结果的搜索工具，后者被描述为需人工过滤、浪费上下文
- 与"闭源托管深度调研服务"可能对立：本文代表的路径是开源+自托管+按 API 用量计费，可审计可修改；闭源 SaaS 的能力边界与数据流不可见
- 与"非 GPT 模型为主"的深度调研实现可能对立：官方明确以 GPT 模型优化和测试为准，并警告其他模型可能出问题——若生态中存在主打开源模型（Ollama/DeepSeek 等）的同类框架，两者在模型中立性上存在张力
