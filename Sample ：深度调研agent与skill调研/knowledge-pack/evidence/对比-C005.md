## 三、开源对照样本（S037 OpenManus + 既有 S015 Manus）

| 维度 | OpenManus（S037，社区开源） | Manus（S015，闭源 SaaS） |
|---|---|---|
| 形态 | 通用 agent 框架（MIT，57.9k stars，MetaGPT 团队社区项目） | 通用 agent 服务（订阅积分制） |
| 开放度 | 本地部署、自带 API key、MCP 支持 | 闭源、云端异步 VM 执行 |
| 架构 | ReAct/toolcall agent loop；多 agent 标注 unstable | Wide Research 并行多代理 |
| 能力边界 | 官方自述 simple implementation | 多输出形态产品矩阵（Mail Manus/Slack/Browser Operator） |
| 与调研的关系 | 通用底座，调研为其中一种任务 | 研究为能力项之一 |

**客观观察**：社区复刻 vs 闭源商业 SaaS 的开放度对照；任务给定 ShilongLee/OpenManus 不存在（GitHub 搜索确认），采录真实主流仓库 FoundationAgents/OpenManus（原 mannaandpoem 已迁移归档）。
