# 采录-S017：Gemini Fullstack LangGraph Quickstart（Google 官方开源仓库）

## 摘要

Google 官方 GitHub 组织 google-gemini 开源的 fullstack 示例仓库（README 标题 "Gemini Fullstack LangGraph Quickstart"，描述 "Get started with building Fullstack Agents using Gemini 2.5 and LangGraph"）：React 前端 + LangGraph 后端 agent，目标是"对用户查询做全面研究"——动态生成搜索词、用 Google Search 查询网页、反思识别知识缺口、迭代精化搜索直到给出带引用的充分支撑答案。README 自述定位为 "research-augmented conversational AI" 示例，全文未出现 "Deep Research" 字样。GitHub API 独立确认（2026-08-04）：18294 stars / 3078 forks / 77 open issues，Apache-2.0 许可，主语言 Jupyter Notebook，2025-05-22 创建、最后推送 2026-06-14，homepage 指向 ai.google.dev Gemini API 的 Google Search 文档。源码独立验证 agent loop：generate_query（gemini-2.0-flash 生成查询）→ 并行 web_research（Google Search grounding tool，temperature=0）→ reflection（gemini-2.5-flash 判定缺口）→ evaluate_research（is_sufficient 或 max_research_loops=2 时结束）→ finalize_answer（gemini-2.5-pro 合成带引用答案），编译名为 "pro-search-agent"。依赖 Google Gemini API key、LangGraph（本地 dev 或 LangGraph Platform 部署：Redis + Postgres + LangSmith）。
