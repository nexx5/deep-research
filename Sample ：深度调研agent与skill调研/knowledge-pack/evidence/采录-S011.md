# 采录-S011：Open Deep Research（nickscamara/open-deep-research）

## 摘要

nickscamara/open-deep-research 是 nickscamara（Nicolas Camara，Firecrawl 创始人）维护的开源深度调研项目（TypeScript/Next.js，Apache-2.0 模板继承，2025-02-03 创建，6278 stars/746 forks）。官方定位为 OpenAI Deep Research 实验的开源复刻，主张用 Firecrawl 的 search+extract（商业抓取 API）+ 推理模型替代 OpenAI 微调版 o3 来深度调研 web。架构为基于 Vercel ai-chatbot 模板的 Next.js 全栈聊天应用：router 模型（默认 gpt-4o，streamText maxSteps=10）编排四个工具（search/extract/scrape 全走 Firecrawl、deepResearch 为内置 agent loop）；deepResearch 默认 maxDepth=7、硬编码 4.5 分钟时限，循环执行 搜索→抽取前 3 个 URL→推理模型（默认 o1-mini）JSON 分析规划（summary/gaps/shouldContinue/nextSearchTopic/urlToSearch）→迭代→最终综合（maxTokens 16000）。数据持久化依赖 Vercel Postgres（Neon）+ drizzle、Vercel Blob、Upstash Redis 限流。需多个付费 API key（OpenAI/OpenRouter、Firecrawl、Postgres/Blob、Upstash、TogetherAI 可选），无单次成本数据。检索通道完全依赖 Firecrawl 单一商业 API，无自建抓取管道。2025-05-07 后无提交（访问时点已停止维护约 15 个月）。

## characteristics

- 检索通道策略：Firecrawl 商业 API 单一供应商（search/extract/scrape 三工具统一）（C2）
- 双模型架构：router（gpt-4o）+ reasoning（o1-mini 默认）（C3）
- agent loop：搜索→抽取→推理分析规划→迭代→综合（C4）
- 深度与时间硬限制：maxDepth=7、4.5 分钟内部时限、serverless 300s/Hobby 60s（C5、C11）
- 多模型供应商：OpenAI/OpenRouter/TogetherAI/AI SDK（C6）
- JSON schema 约束与 BYPASS_JSON_VALIDATION（C8）
- 云基础设施依赖：Vercel Postgres/Blob + Upstash Redis（C9）
- 自托管可行但检索商业 API 锁定（C10、C13）
- 流式进度 UI + 来源 favicon + 双模式切换（C12）
- 模板继承：Vercel ai-chatbot 基础（C17）
- 已停止维护：2025-05-07 后无提交（C14）
- 无官方成本数据、无专门免责声明（C16、C18）
