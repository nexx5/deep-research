## summary

本来源是三份独立第三方评测的合并采录（源A DeepResearch Bench 学术基准 / 源B Section AI 真实任务实测 / 源C AIMultiple 商业评测基准），属于"外部独立验证"类证据，是"官方声称 vs 独立验证"对照主轴的关键补充。三份评测共同点：均非厂商自报，方法/样本均公开（任务数、ground truth、judge 口径、评分标准）。各来源结论差异显著且不矛盾——源A 显示 Gemini-2.5-Pro DR 报告质量（RACE 48.88）与有效引用数（111.21）双高，Perplexity DR 引用准确率最高（90.24%）；源B（2025-03，n=1）判 ChatGPT DR 胜出、Gemini 输出不可用；源C（2026-04/06）显示 agent CLI 类（Claude Code/Codex 93.9-97%）在检查点准确率与成本上优于付费 DR 模型（o3/o4-mini 75.8-81.8%，成本 2-6 倍于 Sonar），且 Grok 快 10 倍、Gemini 最慢（62 源/15+ 分钟）。关键观察：第三方评测普遍自建"报告质量/引用准确率/事实核查"指标，未对官方 HLE/GAIA/SimpleQA 自报分数做同基准复测——因此独立验证补充的是"另一类能力"的证据，与官方自报分数维度不同、不可直接对等。评测模型版本窗口（2025-03 ~ 2026-06）不一致，横向对比须谨慎。

## characteristics

- 独立第三方评测（学术/实测/商业三类型）
- 评测方法与样本公开
- 自建指标（报告质量/引用准确率/检查点）
- 量化数据（准确率/成本/延迟/来源数/引用数）
- 模型版本窗口差异（2025-03 ~ 2026-06）
- 结论多任务分歧（引用准确率 vs 格式合规 vs 输出质量）
- 官方 HLE/GAIA/SimpleQA 无独立同基准复测（缺口）
- 利益相关：学术团队 / 内部员工 / 商业咨询机构

## opposing_to

- 与"付费 deep research 服务官方自报基准分"（Batch1 采录的 ChatGPT/Perplexity/Gemini DR 官方 HLE/GAIA/SimpleQA 声称）形成**对照而非直接对立**：独立评测补充的是报告质量/引用/事实核查类证据，官方自报是知识问答类——两者指标维度不同，若被当作同维度比较会产生误导（客观陈述）
- 与"付费 DR 模型不可替代论"可能对立：AIMultiple 数据显示 agent CLI 类（Claude Code/Codex/Parallel）在检查点准确率与成本上均优于付费 DR 模型（97%/$1.30-2.10 vs 75.8-81.8%/$10.92）——第三方观察，暗示深度调研能力的实现路径存在替代方案
- 与"来源数量=质量"的隐含假设对立：源A 与源B 均显示来源多≠输出好（Gemini 有效引用 111.21 但实测输出被评不可用；Sonar 5253 词但不比 398 词的 agent 更准）；AIMultiple 明示"更多词与更多引用不预测更高准确率"
- 与"深度研究模型即最终产品"的认知可能对立：AIMultiple Unity 案例显示专业外观报告可含错误数值（o3 给错 Android API），提示报告级输出需事实核验——但本来源只记录该观察，不形成"深度研究不可用"结论
