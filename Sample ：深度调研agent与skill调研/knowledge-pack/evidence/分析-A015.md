## summary

Manus 是"通用 AI Agent"形态的闭源商业 SaaS 代表：官网展示其能力矩阵（网页应用/Wide Research/浏览器操作/设计/幻灯片/图像音乐生成/Mail/Slack 集成），核心研究能力 Wide Research 采用"主代理-子代理并行"架构，声称通过"每项目新上下文 + 子代理隔离通信"解决上下文过载，工作流为任务分解→并行执行→自动化→汇聚综合，输出形态覆盖报告/数据集/网站/幻灯片。定价为积分制（免费每日300积分；Pro $20/$40/月，积分4000/8000起，20并发任务）。官方通过积分退款政策间接承认失败场景（平台错误/工具误用/执行不完整可退款，外部因素/指令模糊不退款）。产品背景受 2025-12 Meta 约20亿美元收购、2026-04 发改委命令撤销、2026-06 Meta 开始拆分影响，截至采录日官网仍标注 Meta 归属。本源以营销声明为主，社区成功率争议为重要对冲证据（第三方转述）。

## characteristics

- 通用agent（非专用深度调研）
- 多代理并行 + 主从协调
- 每项目新上下文（上下文隔离）
- 积分计费订阅制
- 闭源商业SaaS + 开放API
- 云端异步任务执行
- 营销声明主导（官方声称为主）
- 收购与监管反转背景（2025-12→2026-04→2026-06）
- 模型依赖外部底层（Claude/Qwen，社区信息）

## opposing_to

- 与"专用深度调研工具"形态可能对立：Manus 的研究能力（Wide Research）是通用 agent 的一个能力项，与以证据链/知识包为核心的专项深度调研产品在深度、证据管理与可追溯性上取向不同
- 与"开源框架/自托管"形态可能对立：Manus 闭源 + 云端 VM 执行 + 积分计费，与开源 agent 框架（用户自持上下文/模型/数据）在开放度、成本结构、数据主权上对立
- 官方"并行代理+新上下文保证规模化质量"声称 vs 社区"复杂任务卡壳数十小时、上下文整合弱"反馈，构成对立证据组
- 与 OpenAI DeepResearch 可能直接竞争（官网提供 vs-chatgpt 比较页，早期 GAIA 基准对比为宣传卖点）
