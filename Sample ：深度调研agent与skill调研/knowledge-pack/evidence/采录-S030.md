## 摘要

四个多 agent 框架 GitHub 仓库主页概览合并采录（全部仓库官方 README 自述，非独立验证）：**CAMEL**（camel-ai，Apache-2.0，17.5k stars）——以"寻找 agent 规模化定律"为定位的开源研究社区，设计原则含 Evolvability/Scalability（支持模拟百万级 agents）/Statefulness/Code-as-Prompt，明示 Multi-Agent Research Assistant（文献综述协作）与 Role-Playing Scraper（报告与知识图谱生成）等调研类用例。**MetaGPT**（FoundationAgents，MIT，69.7k stars）——"软件公司 as 多 agent 系统"（Code = SOP(Team)），一行需求输出用户故事/竞争分析/需求/API/文档，含 Data Interpreter 数据分析与 Researcher 用例；2025 年发布产品化 MGX（mgx.dev）与 AFlow 论文（ICLR 2025 oral）。**OpenAI Swarm**（openai，MIT，21.9k stars，仅 29 commits）——实验性教育框架，Agents+handoffs 两原语、完全基于 Chat Completions API 且调用间无状态；README 明示已被 OpenAI Agents SDK 取代并建议迁移。**Microsoft AutoGen**（microsoft，文档 CC-BY-4.0+代码 MIT，60.2k stars）——可自主或人机协作的多 agent 应用框架，分层设计（Core/AgentChat/Extensions），含 AutoGen Studio no-code GUI 与 Magentic-One 多 agent 团队（web browsing/code execution/file handling）；README 明示进入 maintenance mode，由 Microsoft Agent Framework（MAF 1.0，A2A+MCP 互操作）接替。跨源观察：四框架均为通用多 agent 编排框架（非深度调研专用），调研类用法为场景之一；维护状态分化（Swarm 被取代、AutoGen 维护模式、CAMEL/MetaGPT 活跃）；四仓库主页均未见对 Cognition《Don't Build Multi-Agents》批评的直接回应。
