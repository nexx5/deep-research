## summary

OpenManus 作为 MetaGPT 团队 3 小时开发的 Manus 开源复刻，核心论点是"通用 agent 能力无需闭源 SaaS 与邀请码即可获得"：以 MIT 许可、本地部署、用户自带 LLM API key 的方式，用单 agent ReAct/toolcall 循环 + browser-use/computer-use/crawl4ai 等开源工具集复刻 Manus 的核心执行能力。证据来自仓库 README 的自我定位、配置/运行文档与代码目录结构；其能力边界由官方自述的"简洁实现、多 agent 版本不稳定"划定，且社区热度（57.9k stars）显著高于其衍生 RL 项目（4.1k stars）。

## characteristics

- 开源（MIT）
- 通用agent框架
- 社区项目（MetaGPT 团队）
- 本地部署 + 自带API key
- 浏览器/计算机/爬取工具集成
- ReAct/toolcall agent loop
- 多agent（unstable）
- MCP支持
- 高社区热度
- 官方自述局限

## opposing_to

- 与"闭源商业 SaaS 通用 agent（Manus）"特点可能对立：OpenManus 以"无需邀请码、开源免费、本地部署、自带 key"为立身主张，直接对冲 Manus 的云端订阅积分制（S015 对照），开放程度维度上构成正反对照
- 与"托管的开箱即用 agent 服务"特点可能对立：OpenManus 需用户自行配置 LLM API、安装依赖（conda/uv、playwright），无托管执行环境，属于 DIY 自托管路线
- 与"产品化多代理编排"特点可能对立：OpenManus 官方标注多 agent 版本 unstable，与 Manus Wide Research 并行多代理（S015）及 Cline/OpenHands 等成熟多代理编排形成能力差距
