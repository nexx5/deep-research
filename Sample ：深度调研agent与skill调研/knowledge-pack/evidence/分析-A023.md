## summary

本来源是五个新形态付费 Deep Research 服务官方页的概览合并采录（源A Kimi Deep Research / 源B Parallel / 源C Azure AI Foundry Deep Research / 源D Claude Research / 源E Grok DeepSearch），属于"付费侧产品形态矩阵"的关键补充——S013 第三方评测揭示了这些条目但未覆盖官方形态，本批以官方声明补齐。五条目可划分为两类形态：**消费者应用内功能**（Kimi 免费层+token 计费、Claude 付费订阅、Grok X Premium 门槛）与**面向 agent 的 API 基础设施**（Parallel Task API 按请求计费、Azure Foundry o3-deep-research 按 token 计费的企业化封装）。核心观察：(1) 官方功能命名不统一（Kimi/Azure 用 "Deep Research"、Claude 支持页用 "Research"、Grok 用 "DeepSearch"、Parallel 用 "Task API"），第三方评测另有称呼（如 "Claude Deep Search"）；(2) 定价存在 token/请求/订阅三种哲学，Kimi 与 Parallel 提供免费层；(3) 全部为厂商官方声称，其中 Parallel 的自建六基准为自报评测，未经独立验证——与 S013 第三方实测（Grok 快 10 倍、Claude 261 源/6 分钟、Parallel Ultra 97%）构成"官方形态 vs 独立实测"对照锚点，两者维度不同、不可直接对等。概览 light 档：本批只记录官方声称与形态差异，不深挖不评判；各条目深挖方向已列为线索。

## characteristics

- 官方产品页/公告/文档为主要来源
- 五条目多源合并概览（分节标注 URL）
- 消费者应用内功能 vs agent API 基础设施两类形态
- 定价模式三分（token/请求/订阅）
- 免费层存在（Kimi/Parallel）
- 引用与可审计输出成为共同卖点（Parallel Basis/Azure/Kimi/Claude）
- 命名不统一（Deep Research/Research/DeepSearch/Task API）
- 企业合规差异化（Parallel SOC2/HIPAA；Azure 企业治理；Grok 订阅门槛）
- 官方自建基准（Parallel，自报性质）
- 概览 light 档：未深挖，深挖方向已列线索

## opposing_to

- 与"付费深度研究=消费者聊天附加功能"的认知可能对立：本批显示付费侧已分化出"面向 agent 的 API 基础设施"形态（Parallel Task API、Azure Foundry agent tool）——深度研究正成为可编程、可组合的企业/agent 服务而非仅聊天功能（客观陈述）
- 与"官方声称=事实"的隐含假设对立：本批五源全部为厂商自报（Parallel 自建基准、Azure 架构描述、Grok 公告口径），S013 第三方实测与之维度不同（官方声称测的是形态与自报能力，第三方测的是任务级准确率/速度/来源覆盖）——两者不可直接对等，需分轨对待
- 与"开放度统一"假设对立：五条目开放度差异显著——Grok 仅 X Premium+ 用户/Enterprise API 计划、Claude 仅付费订阅、Kimi 免费层+付费、Azure 有限公开预览 API、Parallel 免费层+开放 API；"深度研究付费服务"内部开放度并非一致（客观记录）
- 与"成本结构统一"假设对立：token 计费（Azure o3 $10 输入/$40 输出）、请求计费（Parallel $1/1000）、订阅内额度（Claude/Grok）三种哲学并存，成本可比较性低（客观记录，不评判优劣）
