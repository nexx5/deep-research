# 分析-A001：GPT Researcher 单源分析

## summary

GPT Researcher 是 assafelovic 的开源深度调研 agent（Python，Apache-2.0，v3.6.0，2026-07 发布，28.8k stars，官网 gptr.dev），官方自述为"首个开源深度调研 agent"。其价值主张围绕：解决人工调研耗时（周级）、LLM 幻觉与过时信息、token 限制无法生成长报告、现有服务来源有限导致浅层与偏见。架构核心是 planner/execution/publisher 三阶段 agent loop；Deep Research 模式为树状递归探索；多 agent 变体基于 LangGraph/AG2（STORM 启发）；检索默认 Tavily + 可选 MCP；可观测性走 LangSmith。本源的证据形态为官方 README 与 release 自述——**全部主张属"官方声称"层级**，其中仓库存在性、license、版本号、stars 等元数据经 GitHub API 独立确认；性能/成本/质量类宣称（~$0.4/次、5 分钟/次、无偏报告、20+ 来源）均无独立基准验证。**关键源偏差**：任务指派来源 assafelovic/deep-research 已不存在（404），本分析基于真实存在的同作者主项目 gpt-researcher；README 自述"first open deep research agent"，与任务描述的"OpenAI Deep Research 开源复刻"定位不一致，该差异属任务假设与官方声称的冲突，交由合并员核验。

## characteristics

- agent loop 三阶段编排（planner→execution→publisher）
- 树状递归探索型 Deep Research 模式
- 多源检索（Tavily web + MCP 数据源 + 本地文档）
- 多 agent 协作（LangGraph/AG2，STORM 方法流派）
- 证据引用与来源追踪（citations/source-track）
- 长报告生成（2000+ 词、PDF/Word/Markdown 导出）
- 显式成本数据（官方给出 ~$0.4/次、~5 分钟/次）
- 开源自托管（Apache-2.0、pip/Docker/本地服务）
- MCP 双向集成（client 接入 + server 独立仓库）
- LangSmith 可观测性
- 官方减偏方法论（多源取众）
- 官方实验性免责声明（不推荐学术使用）

## opposing_to（可能对立的方向，客观陈述）
