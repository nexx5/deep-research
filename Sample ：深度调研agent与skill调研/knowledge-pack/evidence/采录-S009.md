## 摘要

dzhng/deep-research（README 标题 "Open Deep Research"）是社区最热门的 OpenAI Deep Research 开源复刻之一，作者 David Zhang（dzhng，Duet 出品），2025-02-04 创建，TypeScript 实现。官方定位为"最简 deep research agent 实现"，声称目标代码量 <500 LoC。架构核心是单函数递归循环（deepResearch 自调用）：LLM 生成 SERP 查询 → Firecrawl 搜索+抓取 markdown → LLM 提取 learnings 与后续研究方向 → depth>0 时递归深入（depth 减 1、breadth 减半）→ 最终 LLM 生成 ≥3 页 Markdown 报告并附 Sources。搜索/抓取全部依赖 Firecrawl 服务，无自研爬虫；无独立规划器/记忆模块，learnings 与 visitedUrls 数组随递归传递、不持久化。模型默认 OpenAI o3-mini，支持本地 LLM（OPENAI_ENDPOINT）、DeepSeek R1（Fireworks）、自定义 endpoint。支持 Docker 与 HTTP API（express）。GitHub API 独立验证：19,474 stars、1,988 forks、93 open issues、MIT 许可证（LICENSE 文件）但 package.json 标 ISC（不一致）、无正式 release。该来源是"单 agent 递归深化"方法流派的核心样本，与多 agent 编排型实现（如 OpenDeepResearch）构成方法论对立。
