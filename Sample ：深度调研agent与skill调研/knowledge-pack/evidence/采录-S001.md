# 采录-S001：GPT Researcher（assafelovic/gpt-researcher）

## 摘要

GPT Researcher 是 assafelovic 维护的开源深度调研 agent（Python，Apache-2.0，v3.6.0，28.8k stars，2023-05 创建）。官方自述为"首个开源深度调研 agent"，面向 web 与本地文档，产出带引用的详细、事实性、无偏研究报告。核心架构为 planner（生成研究问题）+ execution agents（收集信息）+ publisher（聚合报告）的 agent loop；提供 Deep Research 树状递归探索模式（官方声称约 5 分钟/次、约 $0.4/次，o3-mini high）。支持多源检索（默认 Tavily + 可选 MCP client 接入 GitHub/数据库/自定义 API）、20+ 来源聚合、2000 字以上长报告、图片抓取与 AI 内联配图（Gemini Nano Banana）、全程记忆与上下文保持、PDF/Word 导出。部署方式多样（pip / Docker / uvicorn 本地服务 / NextJS 前端）。多 agent 变体基于 LangGraph 与 AG2（受 STORM 论文启发）。可观测性走 LangSmith。MCP server 已迁移至独立仓库 gptr-mcp。README 免责声明自认实验性项目、as-is、不推荐用于学术论文。

## characteristics

- agent loop：planner/execution/publisher 三阶段编排（C2）
- 树状递归探索：Deep Research 模式，可配深度广度（C6）
- 多源检索：Tavily web + MCP 数据源 + 本地文档（C5）
- 多 agent 协作：LangGraph / AG2 / STORM 启发（C8）
- 证据引用与来源追踪：citations / source-track（C4、C3）
- 长报告生成：2000+ 词、PDF/Word/Markdown 导出（C4、C8）
- 成本可测：官方给出 ~$0.4/次、~5 分钟/次（C7）
- 开源自托管：Apache-2.0、pip/Docker/本地服务（C10、C13）
- MCP 双向：client 接入 + server 独立仓库 gptr-mcp（C11）
- 可观测性：LangSmith tracing（C12）
- 官方减偏方法论：多源取众（C15）
- 实验性定位：官方免责声明（C14）
