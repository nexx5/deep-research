# 采录-S016：OpenAI Operator 官方发布页

## 摘要

OpenAI 官方发布页（2025-01-23）宣布 Operator：一个拥有自己浏览器的 agent（research preview），可替用户执行网页任务（打字/点击/滚动）。由新模型 Computer-Using Agent (CUA)（GPT-4o 视觉 + 强化学习推理）驱动，通过截图"看"、鼠标键盘动作"交互"，无需自定义 API 集成；官方声称 CUA 在 WebArena 和 WebVoyager 浏览器使用基准上刷新 SOTA。发布初期仅限美国 Pro 用户在独立站 operator.chatgpt.com 使用。页面含 2025-07-17 更新：Operator 已整合进 ChatGPT（agent mode），独立站即将关停。全部内容为官方声称，无第三方验证。

## characteristics

- 浏览器代理（browser-use agent）
- 任务执行型（action execution，非调研/信息综合型）
- CUA 模型（GPT-4o 视觉 + RL）
- 免 API 集成（操作 GUI 而非调用接口）
- 人工接管/协作模式（takeover mode）
- 安全三层防护（用户控制/数据隐私/对抗防御）
- research preview 起步
- 官方营销声明为主（无第三方验证）
