## 摘要

S038 五源合并采录（采录档位混合：两篇论文源 deep，三个框架源 light）。① DeepResearchEval（arXiv:2601.09688，2026-01-14）：自动化深度调研任务构建+agentic 评估框架，persona-driven 任务生成管线+两级过滤（Task Qualification / Search Necessity），评估侧 Adaptive Point-wise Quality Evaluation（按任务动态推导评估维度/标准/权重）+ Active Fact-Checking（网络搜索自动验证报告陈述，citation 缺失时仍可验证）；与既有 DRB 家族（USTC DRB I/II、FutureSearch DRB）**量纲独立**（摘要未提及 DRB 家族任何基准名，为独立评测方法论框架）。② OpenAI Agents SDK（MIT，28k stars）：轻量多 agent 工作流框架，provider-agnostic，核心概念含 Sandbox agents/Handoffs/Tracing；README 未提及 Swarm。Microsoft Agent Framework（MIT，12.6k stars）：生产级 .NET+Python 多 agent 框架，README 明确提供 AutoGen 与 Semantic Kernel 迁移指南。③ DeerFlow（bytedance/deer-flow，MIT，79k stars）：官方仓库为小写 deer-flow（任务给定 DeerFlow 404）；2.0 为 ground-up rewrite，定位从 Deep Research 框架转型为 super agent harness（LangGraph/LangChain 底座），skills/沙箱/子 agent/长时记忆/上下文工程为主要特性。WebThinker（arXiv:2504.21776，NeurIPS 2025）：人大 RUC-NLPIR 团队深度研究 agent，赋能 LRM（o1/DeepSeek-R1 类）推理中自主搜索/导航/起草，Deep Web Explorer + Think-Search-and-Draft + 迭代在线 DPO 训练，在 GPQA/GAIA/WebWalkerQA/HLE/Glaive 上显著优于现有方法与强专有系统。MisKnow-Agent 评估：本次抓取的 README/摘要均未提及。
