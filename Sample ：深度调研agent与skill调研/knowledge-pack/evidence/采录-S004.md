## 摘要

hyperresearch（jordan-gibbs/hyperresearch）是将 Claude Code 转变为深度调研 agent 的开源 skill/harness：16 步分层流水线 + 对抗性审查 + 引用验证 + 持久化可搜索 vault，MIT 许可，PyPI 发布（0.10.0）。官方声称当前在 DeepResearch-Bench RACE 榜领先，但明确标注为内部基准、第三方验证 pending。
