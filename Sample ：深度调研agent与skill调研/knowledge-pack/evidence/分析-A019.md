# 分析-A019 hyperresearchbench 单源分析

## summary

本来源是一条**官方附属的评测复现工具**证据链：完整描述了 hyperresearch 在第三方基准 USTC DeepResearch-Bench 上的评测方法（100 条任务、RACE+FACT 双指标、Gemini LLM-as-judge）、被测配置（full tier 16 步 pipeline、Opus/Sonnet/Haiku 分层）、成本数据（单 query 约 $60–120、约 1.5–2.5 小时，100 条约 6–10 天），以及官方"领先"声称的限定措辞（benchmarked internally、stratified pilot n=9、57.77 分、超 xiaoyi 0.77 分、第三方验证 pending）。

从证据链角度看，本来源回答了"hyperresearch 的 benchmark 领先声称是如何产生的、由谁产生、证据强度如何"：**声称产生于官方自己的分层试点（n=9），评估器与任务集来自第三方基准但运行方与评分主体均为官方配置，且官方明确声明第三方验证尚未完成**。完整 100-query 复现结果未发布。

## characteristics（跨源关联用）

- 官方附属基准（利益相关：作者与主仓库相同）
- 复现 harness（非独立评测工具）
- 任务集来自第三方（USTC DRB 100 query）
- RACE + FACT 双指标（Gemini-2.5 LLM-as-judge，跨供应商评估被测的 Claude 系）
- 被测配置：full tier 16 步对抗审查 pipeline
- 成本：per-query ~$60–120 / ~1.5–2.5h；100 条 ~6–10 天
- 官方分数基于 stratified pilot（n=9）
- 官方措辞分层：benchmarked internally → forward-looking projection → third-party validation pending
- 完整 100-query 结果未发布（results/ 仅 .gitkeep）
- 仓库未采用（0 stars / 1 fork / 单次提交）

## opposing_to（可能对立的方向，客观陈述）

1. **官方声称 vs 独立验证分层**：本来源全部"领先/分数"为官方自称（benchmarked internally、n=9 pilot）；官方自认 "Third party validation is pending"。任何将 CL6/CL7 当作独立第三方验证结论使用的表述，与本来源的证据边界对立。
2. **pilot（n=9）vs 完整评测（100 条）**：官方分数基于 9 条分层抽样，而 leaderboard 声明指向完整 100 条基准；两者样本量不对等，官方 README 自述完整复现正是 harness 存在的目的（隐含完整结果尚未产生）。
3. **评估自运行 vs 独立复现**：评分过程（Gemini judge 调用、FACT 引用爬取）由官方 harness 编排并运行，无独立第三方复现记录；README 声称的复现预期（±2 分）未被独立验证。
4. **生态对照**：与 LiveResearchBench 等实时任务基准相比，DRB 为静态 100 任务集，评测方法论不同（静态参考报告 vs 实时信息收集），两者对 deep research 能力的测量范围可能不同。
