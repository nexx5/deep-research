# 采录-S034：OpenAI《Operator System Card》

## 摘要

OpenAI 官方安全文档（System Card，2025-01-23 发布；2025-03-11 追加 API 安全披露段），在 Operator（CUA 模型研究预览）发布前完成的安全工作全披露：外部红队（20 国 24 语言）、按 Preparedness Framework 的前沿风险评估（CBRN biorisk tooling 1%、模型自主性主任务≤10%，均判 Low 与 GPT-4o 一致）、三类风险缓解（harmful tasks / model mistakes / prompt injections）的分层设计（模型训练、系统级检查、产品设计、持续策略执行）。披露关键评测数字：agentic 危害拒绝率 97%、confirmations recall 92%、watch mode、prompt injection 缓解（31 场景 23% vs 无缓解 62%）、prompt injection monitor（77 次红队注入 recall 99%/precision 90%、误报 46/13,704）、未缓解模型 100 提示 13 错误。本文为浏览器代理流派（执行侧）安全设计/评测/失败场景的一手官方证据，与 CUA 技术博客（S032）和 Operator 官方页（S016）构成安全维度三角。
