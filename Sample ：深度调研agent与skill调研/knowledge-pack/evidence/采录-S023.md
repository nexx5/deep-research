## 摘要

五条目新形态付费 Deep Research 服务官方页概览合并采录（全部官方声称，非独立验证）：**Kimi Deep Research**（Moonshot AI，kimi.com）——消费者应用内功能，澄清式三阶段工作流（澄清→自主执行→多格式产出），免费计划可用、按 token 计费，支持 Markdown/PDF/PPT/Word/Excel/交互式 HTML 多格式与同会话多轮迭代。**Parallel**（parallel.ai）——面向 AI agent 的 web 搜索与研究 API 平台，自研 web-scale 索引，产品套件 Search/Extract/Responses/Task（深度研究）/FindAll/Monitor，Task API 输出带引用+校准置信度（Basis 框架），按请求计费（搜索低至 $1/1000 请求，$5/月免费额度），SOC 2/HIPAA/零数据留存。**Azure AI Foundry Deep Research**（Microsoft）——OpenAI o3-deep-research 的 API/SDK 企业化封装（2025-07-07 公开预览），五步流水线（GPT 澄清→Bing Grounding→o3 执行→可审计输出→API 组合），定价输入 $10/输出 $40 per 1M tokens。**Claude Research**（Anthropic，官方支持页命名 "Research"，第三方称 "Claude Deep Search"）——付费计划（Pro/Max/Team/Enterprise）应用内 agentic 研究功能，多轮自衔接搜索+可核查引用，可跨 Gmail/Calendar/Docs 内部上下文，无独立 API 描述。**Grok DeepSearch**（xAI）——2025-02-19 Grok 3 公告发布的 xAI 首个 agent，面向 X/Grok.com 用户（Premium+ 立即获得），公告称将经 API 向 Enterprise 提供；另有独立层面 Web Search 工具 API（grok-4.5 支持 web_search 工具）。形态观察：五条目分属"消费者应用内功能"（Kimi/Claude/Grok）与"面向 agent 的 API 基础设施"（Parallel/Azure）两类；定价分 token/请求/订阅三种模式；全部为官方自报（Parallel 含自建基准），与 S013 第三方实测可作对照。
