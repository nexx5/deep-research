## summary

本来源是四个多 agent 框架（CAMEL / MetaGPT / OpenAI Swarm / Microsoft AutoGen）GitHub 仓库主页的概览合并采录，属于"多 agent 方法流派生态基础设施"的关键补采——S021 Cognition《Don't Build Multi-Agents》点名批评了这四者，本批以各仓库官方主张补齐对立面证据。核心观察：(1) 四框架均为**通用多 agent 编排框架**（非深度调研专用），调研类用法（CAMEL Multi-Agent Research Assistant 文献综述协作、MetaGPT Researcher 用例、AutoGen Magentic-One web browsing）只是适用场景之一——与 S002 OpenDeepResearch（深度调研专用多 agent 方案）构成"通用编排层 vs 场景专用方案"的流派对照；(2) 维护状态显著分化：OpenAI Swarm 已被 Agents SDK 取代（29 commits 实验项目）、AutoGen 进入 maintenance mode 由 Microsoft Agent Framework 接替，而 CAMEL/MetaGPT 仍活跃——多 agent 框架生态正在经历"实验框架→生产级继任者"换代；(3) 四个仓库主页均未见对 Cognition 批评的直接回应，回应/讨论可能存在于 issue/discussion/博客层（已列线索）。全部为仓库官方 README 自述（官方声称），其中"1M agents 模拟""state-of-the-art""ProductHunt #1"等为自报/自评表述，未经独立验证。概览 light 档：只记录官方主张与生态状态，不评判优劣；Cognition 批评与四框架主张客观并列不判对错。
