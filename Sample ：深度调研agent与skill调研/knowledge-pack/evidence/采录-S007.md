# 采录-S007：Gemini Deep Research 官方说明合集

## 摘要

本来源为 Google 官方 Deep Research 说明合集（6 个官方页面）：专项产品页、API 开发者文档、官方发布文、Gemini Apps 帮助中心（使用+额度）及 Gemini 概览页。官方宣称：Deep Research 是 Gemini 中"agentic"功能，自主规划→研究→综合三步工作流，自动浏览数百网站乃至用户 Gmail/Drive/Chat，数分钟内生成多页带引用报告；架构上采用异步任务管理器（失败可恢复、可离线等通知）+ 1M token 上下文窗口 + RAG；2025-12-11 起通过 Interactions API 开放给开发者（两档：Deep Research / Deep Research Max），推理核心为 Gemini 3 Pro，官方声称在 HLE 达 46.4%、DeepSearchQA 66.1%、BrowseComp 59.2%，并开源 DeepSearchQA 基准；API 定价按用量付费（DR 约 $1-3/任务，DR Max 约 $3-7/任务）；App 端免费/付费分级额度（无计划标准额度、AI Plus 2x、AI Pro 4x、AI Ultra 5x 或 20x），Deep Research 消耗较多用量。官方文档明确披露多项局限：不支持自定义 Function Calling（可用 MCP 替代）、不支持结构化输出、单任务最长 60 分钟（多数 20 分钟内完成）、必须后台执行、安全风险（提示注入/网页内容风险/数据外泄）。

- 付费服务代表方案（Google 系）：订阅分层（免费/Plus/Pro/Ultra）+ API 按用量付费双轨
- API 开放程度高：Interactions API、Google AI Studio、MCP 支持、File Search、未来 Vertex AI
- 架构流派信号：agentic 三步工作流（Plan→Search→Read→Iterate→Output）+ 异步任务管理器 + 1M 上下文+RAG + 多步强化学习训练
- 双档产品线（Deep Research 标准版/Max）+ 协作规划 + 可视化 + 多模态输入
- 成本透明化：API 文档给出每任务 token/搜索量估算与 $1-7 成本区间（付费组核心对比参数）
- 官方披露局限较全面：无自定义函数/无结构化输出/60 分钟上限/后台执行要求/安全风险
- 官方文档内部矛盾：发布文称支持结构化输出（JSON schema），API 文档 Limitations 称不支持
- 基准自我宣称（HLE 46.4% / DeepSearchQA 66.1% / BrowseComp 59.2%）需第三方验证
- 客户证言（金融/生物科技）为营销性个案，无独立数据
- 免费额度具体次数（5次/月 vs 20次/日）未在本来源主文档披露，需补第三方/帮助中心专项页
