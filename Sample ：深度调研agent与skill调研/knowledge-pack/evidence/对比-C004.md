# 跨源对比-C004：深度调研生态版图补全（框架内置 / 浏览器代理 / 多agent框架 / 评测基准家族 / 攻击面）

## 一、agent 框架内置深度研究能力（S026）

| 框架 | 内置 deep research 能力 | 形态 | 证据 |
|---|---|---|---|
| LangChain | **有**官方 deep research 构建指南（docs.deepagents/deep-research）+ deepagents harness（MIT，27.3k stars） | 官方教程 + harness 能力（subagent 委派/任务规划/虚拟文件系统/MCP） | S026 官方文档 BM25 搜索验证 |
| LlamaIndex | **无**专用 deep research 功能页（BM25 全站搜索未命中） | 框架原语（multi-agent 模式）+ 第三方集成（Perplexity Sonar 等） | S026 官方搜索 API 验证（"未发现"已注明搜索范围） |

**客观观察**：两框架路线不同——LangChain "官方教程+harness" vs LlamaIndex "框架原语+自建"。这与独立开源项目（OpenDeepResearch S002、dzhng S009）构成"框架内置 vs 独立项目"两种产品形态。

## 二、浏览器代理流派（S032 CUA + S016 Operator + S025 Perplexity Computer）

| 方案 | 底座 | 接口哲学 | 评测数据（官方声称） | 与 deep research 关系 |
|---|---|---|---|---|
| OpenAI Operator（S016/S032） | CUA（GPT-4o 视觉+RL） | 通用界面（screen/mouse/keyboard），无专用 API | OSWorld 38.1%（人类 72.4%）、WebArena 58.1%（人类 78.2%）、WebVoyager 87% | 执行侧；官方"异步调研+现实执行"组合愿景 |
| Perplexity Computer（S025） | Search as Code 架构 | 计算机宿主 + 20+ 模型路由 | 官方未披露 benchmark | Deep Research 并入 Computer 宿主 |
| Anthropic computer use / Google Project Mariner（S032 引） | 竞品浏览器代理 | 同上 | previous SOTA 对照（Anthropic 22.0%） | 浏览器代理流派竞品 |

**流派对照**：浏览器代理（computer use）与深度调研（deep research）是"执行 vs 调研"两种形态；Perplexity 已把 DR 并入 Computer 宿主（S025），OpenAI 规划 DR+Operator 组合（S005/S016）——付费侧呈现"调研-执行一体"趋势（客观观察）。

## 五、深度调研可靠性/攻击面（S029 + S024 关联）

| 研究 | 攻击/失败类型 | 量化证据 | 受影响对象 |
|---|---|---|---|
| FORGE（arXiv:2607.04718） | 轨迹劫持（规划层攻击/报告污染/推理伪造） | 攻击成功率量化 | 深度调研 agent 通用 |
| MisKnow-Agent（arXiv:2607.20891） | 误导知识采纳（FCAR 错误结论采纳率） | 量化评估 | Gemini DR、DeerFlow、WebThinker |
| Search-Time Contamination（arXiv:2606.05241） | 搜索时污染（性能虚增） | 虚增最高 4% | 公开基准评估 |
| UGC 污染（S024，arXiv:2605.24245） | 检索重叠攻击（UGC 单页污染可操纵引用） | 引用操纵 | 开源+付费 DR |

**对照**：攻击/可靠性研究与付费官方"详细引用/减少幻觉"声称（S005/S007）形成对立/边界对照；与开源侧可见引用机制（S002/S004）在"可审计性 vs 攻击面"上构成开放度维度讨论（客观陈述）。

## 六、方法流派补充（S031 DSPy 论文 + Anthropic）

- **DSPy 论文**（arXiv:2310.03714）：编程式 prompt 编译/自改进管线——论文驱动流派（STORM 技术底座 S018）的学术定义
- **Anthropic《Building Effective Agents》**：workflows vs agents 分类（5 种 workflow 模式）、API 优先、反复杂框架抽象层；将 orchestrator-workers（多 worker 委派）列为合法模式——与 Cognition 默认排除多 agent（S021）存在张力（客观并列）
- **抽象层态度张力**：Anthropic 反复杂框架（建议直连 API）vs DSPy 主张编译器引入抽象——两类方法取向（客观观察）

## 共识

1. **评测基准家族已成体系但量纲割裂**：DRB I/II、FS-DRB、LRB、GAIA 各定义"什么算深度调研能力"，引用必须标注基准
2. **多 agent 框架层快速迭代**：Swarm/AutoGen 被继任者取代（S030），框架生态与深度调研专用方案分层
3. **浏览器代理与深度调研在付费侧融合**（调研-执行一体趋势，S025/S005/S016）
4. **可靠性/攻击面研究成为生态新兴维度**：轨迹劫持/误导采纳/污染三类攻击均有量化证据（S029）

## 分歧（客观列出）

1. **框架内置能力差异**：LangChain 有官方 deep research vs LlamaIndex 无专用页（S026）——框架路线差异非优劣
2. **多 agent 立场张力**：Anthropic 将 orchestrator-workers 列合法（S031）vs Cognition 默认排除多 agent（S021）vs OpenDeepResearch 研究阶段多 agent 有效（S002）——三方立场客观并列
3. **CUA SOTA 声称**：官方"new state-of-the-art"但 WebVoyager 87.0% 与 previous SOTA（Kura 87.0%）并列（S032 已记录，建议官方 eval PDF 核对表格错位）
