## summary

本来源（Perplexity 官方 7 页合集，2026-02 至 2026-07）记录 Deep Research 产品形态的持续演进，是付费侧动态变化的完整时间线证据：架构从单次检索升级为 Search as Code（模型写代码并行跑数千检索步骤）；宿主从独立模式并入 Computer（20+ 模型路由、产出报告/PPT/表格/仪表盘交付物）；Advanced DR 底层模型从 Opus 4.5（2026-02-06）升至 Opus 4.6（2026-02-13）再到 Opus 4.6 Thinking（Max）/4.5 Thinking（Pro，2026-07-16）；产品命名两次收敛（Deep Research→Research；Labs→Create files and apps）；定价分层为 Pro/Max/Enterprise（年付 $17/$167）。核心论点是：深度调研正从"回答复杂问题的模式"演变为"知识工作交付物生产环境"的一部分，官方以三个外部基准（HLE/BrowseComp/DeepSearchQA）佐证并入 Computer 后的能力提升。全部为官方声称。

## characteristics

- 产品演进时间线证据（官方多时间点自述）
- Search as Code 架构（检索即程序）
- 模型路由（20+ 模型）与底层模型升级（Opus 4.6 Thinking）
- 能力扩展（代码沙箱/文档处理/澄清问题/进度显示/报告流式进文件）
- 交付物生产（报告/PPT/表格/仪表盘）
- 付费墙数据源接入（Statista/PitchBook/CB Insights）
- 订阅分层与命名演进

## opposing_to

（客观陈述可能对立方向，不评判对错）

- 与"深度调研=单次检索+长报告"的简化认知对立：官方宣称 DR 是数千步并行 agentic 检索 + 交付物生产闭环
- 与开源深度调研框架（自建检索管线、单模型、可自托管）在架构开放度与模型依赖上形成对立：官方版本依赖专有搜索引擎、商业模型路由与付费墙数据源
- 与"基础模型能力即深度调研能力"观点对立：官方以 DRACO/外部基准强调 agent 编排（search sandbox+代码执行）超出基础模型本身
- 内部并存路线：Advanced DR（单模型 Opus 4.6 Thinking）与 Computer DR（多模型路由）能力侧重不同，可能面对不同用户诉求
