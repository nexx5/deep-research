# 分析-A035：浏览器代理流派评测标尺与竞品

## summary

本来源补全了浏览器代理（computer use）流派的两个外部坐标：**评测标尺**与**竞品**。

评测标尺侧：OSWorld、WebArena、WebVoyager 三个基准构成"从真实计算机到真实网站"的执行侧评估谱系——OSWorld 覆盖跨 OS 的任意应用（369 任务、人类 72.36%+ vs 最佳模型 12.24%），WebArena 聚焦四域真实网站的长任务（GPT-4 14.41% vs 人类 78.24%），WebVoyager 主打真实流行网站 + GPT-4V 自动评估（59.1%，自动评估与人类一致率 85.3%）。三者均开源。

竞品侧：Anthropic computer use（2024-10，Claude 3.5 Sonnet，OSWorld 14.9%/22.0%）与 Google Project Mariner（2024-12，Gemini 2.0 + Chrome 扩展，WebVoyager 83.5%，2025-05 升级为最多 10 任务并行 agent 系统）是除 OpenAI CUA/Operator 之外的两家主要竞品，且三家都在同一批评测基准上自报成绩——说明 OSWorld/WebVoyager 已成为该流派厂商自我标定的公共锚点。

总体画面：该流派由"厂商产品（执行侧）"+"学术基准（评估侧）"两部分构成，厂商自报成绩显著高于基准论文发布时的模型成绩（如 Mariner 83.5% vs WebVoyager 论文 59.1%、CUA 87% vs 论文 59.1%），反映 2024-2025 年间技术快速迭代；同时与人类基线仍有缺口（OSWorld 人类 72.36% vs 厂商最高自报 22.0%）。

## characteristics

- 评测标尺谱系：真实计算机（OSWorld）→ 自托管真实网站（WebArena）→ 在线真实网站（WebVoyager）
- 执行式/自动评估两种评估哲学并存（脚本判定 vs GPT-4V 自动评估）
- 人类基线统一量级：约 72-78%（论文发布时点）
- 厂商自报成绩显著高于论文基线成绩（2024Q4-2025Q1 快速迭代特征）
- 竞品三足：OpenAI CUA/Operator、Anthropic computer use、Google Project Mariner
- 开放度分层：基准全开源；厂商产品闭源（Mariner 限美国 AI Ultra 订阅、computer use 为 beta API）
- 来源可信度分层：论文摘要（H）vs 厂商官方声称（M）

## opposing_to（可能对立的方向）

- **像素级 GUI 执行路线 vs API/工具调用型 agent 路线**：本文全部对象（OSWorld 评估目标、Anthropic、Mariner）都走"看屏幕操作"路线；与依赖专用 API/结构化工具调用的 agent 在接口哲学上对立（同 S032 的 CUA 立场可互证，但需跨源验证）
- **厂商自报成绩 vs 独立评测**：Mariner 83.5%/CUA 87% 的 WebVoyager 自报 vs 论文自身 59.1%，可能反映"评测口径/任务集筛选/代际进步"的差异——厂商自报与第三方独立复测可能存在落差（对立假设，未在本源验证）
- **基准评测的充分性**：WebVoyager 的 GPT-4V 自动评估（85.3% 一致性）vs OSWorld/WebArena 的脚本判定——对"开放式任务能否被可靠自动评估"存在方法论分歧空间
- **开放程度**：全开源基准 vs 闭源厂商产品——开源社区可复现评估，但产品层不可自建，构成生态开放度的对立张力
