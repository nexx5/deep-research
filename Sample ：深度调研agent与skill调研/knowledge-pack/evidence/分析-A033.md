## summary

本文为 Perplexity 官方发布的 DRACO 深研评测基准技术报告（arXiv:2602.11685，Perplexity+Harvard 署名），核心主张：以"真实生产查询"构建跨域基准（100任务/10域/40国来源，五阶段管线），用 LLM-as-judge+专家 rubric（四轴、平均39.3条/任务、负权重）评测前沿深研系统，官方自报 Perplexity DR（Opus 4.6）normalized score 70.5%、全领域全轴领先，同时自列局限（单轮/静态/纯文本/仅英文/黑盒评测）。全部数据为官方声称层级，利益相关（自家产品+自选 judge 框架），需与第三方评测对照。

## characteristics

- 官方基准（Perplexity 自建自评，利益相关）
- 生产数据驱动（真实用户查询，非合成任务）
- 跨域评测（10 领域，40 国信息来源）
- LLM-as-judge + 专家 rubric + 负权重
- 开源（数据集/全 rubric/judge prompt）
- 当前版限单轮/静态/纯文本/仅英文
- 黑盒系统级评测（不分解组件）
- judge 绝对分数漂移但排名稳健

## opposing_to

- 与"第三方独立评测"可能对立：官方自报 70.5% 最高分与被测自家产品存在利益相关，第三方独立复跑（如 OpenRouter 的 DRACO 复跑、S013 AIMultiple DR-50）可能给出不同绝对水平或排名，需对照引用而非并排换算。
- 与"确定性可查基准"方法论可能对立：论文明确批评合成/闭端式基准（GAIA/HLE/BrowseComp 等"challenging but closed-ended tasks"），主张开放结局式生产任务更贴近真实需求；两派评测哲学互斥。
- 与"无权重 pass rate 优先"派可能对立：论文自承加权 normalized score 依赖权重主观性、unweighted pass rate 更稳健，官方主报加权分可能与其对权重敏感，第三方可能倾向不同口径。
- 与 USTC DRB（S010）等学术构建基准在"任务来源与评分方法论"上取向对立（生产查询 vs 学术构建；加权rubric四轴 vs RACE/FACT 双维度）。
