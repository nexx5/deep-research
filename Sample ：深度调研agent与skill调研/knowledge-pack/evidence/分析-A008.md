## summary

Genspark 官网（2026-08-04 抓取）展示的是一个**多模态一站式 AI 工作空间**（版本 6.0），而非纯深度调研工具。官方主张的核心模式是：订阅制 + 积分计量 + 多模型聚合 + 多模态生成 + 办公生态集成。与深度调研直接相关的官方宣称能力为"AI 报告生成器""市场调研工具""AI 事实核查"和"自然语言查数据生成实时仪表盘"四个入口，但全部需要登录后使用，个人定价与免费额度均被登录墙遮挡。该来源是付费深度调研/AI 工作流服务的代表样本，其价值在于呈现"商业闭源 + 订阅"这一流派的产品形态与定价结构，而非可验证的技术能力。

关键观察（客观记录，不评判）：
1. 官网自定位已从"AI 搜索引擎"（早期第三方描述）迁移为"AI 工作空间"，未在主视觉突出"深度调研"专有能力。
2. 定价模式为按席订阅 + 积分计量（12000 积分/席/月），对话与图片生成在限时促销期内"零积分无限"，体现"积分只计超额/高级用量"的常见 SaaS 定价策略。
3. 多模型聚合（8 家对话模型 + 7 家图像模型 + 多家视频/音频模型）是官网最强卖点，但模型可达性与质量无独立证据。
4. 工具子页与个人定价均不可公开访问，官网对"能力细节 + 个人定价"双重不透明。

## characteristics

- 商业闭源 SaaS
- 订阅制 + 积分计量
- 多模型聚合（多家第三方模型）
- 多模态生成（文/图/视频/音频/PPT/文档）
- 办公生态集成（Office 插件/连接器）
- 强登录墙（个人定价与工具详情均不公开）
- 全球化多语言站点
- 产品定位偏"工作空间"而非"深度调研"
- 营销声明主导，独立证据缺失

## opposing_to

- 与"开源深度调研框架"（本地部署、可审计、透明）在对立方向：Genspark 闭源、能力不透明、强登录墙，两者在开放度与可验证性上相反
- 与"纯深度调研专用工具"（如聚焦长文档多源检索与证据链的论文型产品）可能对立：Genspark 强调多模态生成广度，深度调研仅是工具清单中的一项
- 与"单模型直连"方案可能对立：Genspark 以多模型聚合 + 积分墙为核心，单模型方案在成本透明性上不同
- 与"免费增值"定位可能对立：官网公开页未披露免费额度细节，个人定价整体登录墙化
