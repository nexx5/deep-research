## 共识

1. 第三方评测一致认可付费 DR 的**引用与报告质量评估需要独立指标**（RACE/FACT/检查点），官方自报基准分未被独立同基准复测是普遍缺口
2. 社区反馈跨服务共现痛点：**引用质量、配额成本、深度不足**（S014 多平台）
3. Perplexity 引用准确率（90.24%）与 Gemini RACE 总分（48.88）获得第三方量化确认，与官方高排名声称方向一致

## 分歧（客观列出，不判对错）

1. **Gemini 输出质量**：官方声称减少幻觉+详细引用（S007）vs Section AI 实测输出"过于高层级、不可直接使用"（S013B，n=1 样本极小）vs DRB RACE 48.88 第一（S013A，样本 100）——不同评测场景结论方向不同
2. **Perplexity 深度**：官方"数百来源/迭代研究"（S006）vs 社区"15 sources 太浅"（S014）——官方迭代机制 vs 社区感知来源数差异
3. **ChatGPT DR 性价比**：官方 Pro 配额定位 vs AIMultiple"成本 2-6 倍且准确率更低"（单一第三方来源，待验证）
4. **agent CLI vs 付费 DR 对比**：AIMultiple 显示 agent CLI 类（Claude Code 等）成本-准确率更优（S013C）vs 付费 DR 生态存在合理性——产品形态差异（工具型 vs 托管型），非直接竞争结论

## 综合判断（供知识管理员 ingest 的客观归纳，非立场结论）

- "官方声称 vs 独立验证"对照主轴证据已建立：官方自报基准分（HLE/GAIA/SimpleQA）缺独立同基准复测；第三方评测用不同维度指标（RACE/FACT/检查点）补充验证，两者不可直接对等，须在知识包中以"维度不同"边界并存
- 引用可靠性是付费侧最大争议点（社区+学术审计证据 vs 官方声称），与开源侧可见可审计的引用机制形成开放度对比
- 成本披露：官方（除 Gemini DR 外）普遍不透明，第三方有相对成本数据但多为单一来源（验证线索 P1）
