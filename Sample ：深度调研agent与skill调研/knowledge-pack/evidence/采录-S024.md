## 摘要

S024 汇总两项学术证据：其一（arXiv 2604.03173，2026-04）对商业 LLM 与 deep research agent 的引用 URL 进行系统性测量，发现 3-13% 引用 URL 为幻觉（Wayback Machine 无记录）、5-18% 整体无法解析，并发布开源工具 urlhealth 实现自我修正；其二（arXiv 2605.24245，2026-05，Cornell Tech）证明 deep-research agents 因反复检索同一批用户生成内容（UGC）页面而存在污染攻击面——攻击者在单个高频 UGC 页面追加短文本即可使 agent 引用攻击者选定内容，已在 STORM、Co-STORM、OmniThink 三个开源系统上验证。

Next, we argue that this retrieval overlap creates a concentrated attack surface: an adversary who appends a short, crafted text to a single, frequently retrieved UGC page can cause the agent to cite attacker-chosen content and promote attacker-chosen entities across many related queries."
- context: 论文核心主张：检索重叠→集中攻击面→单页污染跨查询生效
