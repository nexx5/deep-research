# 采录-S032：OpenAI《Computer-Using Agent》

## 摘要

OpenAI 官方技术博客（2025-01-23），介绍 Computer-Using Agent（CUA）——支撑 Operator 的模型：以 GPT-4o 视觉 + 强化学习推理为底座，通过"像素感知 + 虚拟鼠标键盘"的通用界面与 GUI 交互，无需 OS/Web 专用 API；给出 OSWorld 38.1%、WebArena 58.1%、WebVoyager 87% 的 SOTA 评测声称（附 previous SOTA 与人类表现对比）；披露 Operator 试用各场景成功率的实测表；阐述三层安全风险（misuse/model mistakes/frontier risks）的缓解设计与提示注入防御。本文为浏览器代理流派（computer use）技术底座的一手官方证据。

## evidence

### 证据1（架构定义，对应断言 1-3）
- source: S032
- location: 导语段
- quote: "Powering Operator is Computer-Using Agent (CUA), a model that combines GPT‑4o's vision capabilities with advanced reasoning through reinforcement learning. CUA is trained to interact with graphical user interfaces (GUIs)—the buttons, menus, and text fields people see on a screen—just as humans do. This gives it the flexibility to perform digital tasks without using OS-or web-specific APIs."
- context: 博客导语对 CUA 的正式定义

### 证据2（工作机制，对应断言 4-6）
- source: S032
- location: How it works 段
- quote: "CUA processes raw pixel data to understand what's happening on the screen and uses a virtual mouse and keyboard to complete actions... **Perception**: Screenshots from the computer are added to the model's context... **Reasoning**: CUA reasons through the next steps using chain-of-thought... **Action**: It performs the actions—clicking, scrolling, or typing—until it decides that the task is completed or user input is needed... CUA seeks user confirmation for sensitive actions, such as entering login details or responding to CAPTCHA forms."
- context: 官方对 CUA 迭代循环机制的完整描述

### 证据3（评测数字，对应断言 7-9）
- source: S032
- location: Evaluations 段（导语 + 评测表 + 正文）
- quote: "achieving a 38.1% success rate on OSWorld for full computer use tasks, and 58.1% on WebArena and 87% on WebVoyager for web-based tasks"；"Human performance on this benchmark [OSWorld] is 72.4%"
- context: 导语与评测章节正文一致陈述；评测表给出 previous SOTA 链接（Anthropic 22.0%、ServiceNow browsergym 36.2%、Kura 56.0%/87.0%）
