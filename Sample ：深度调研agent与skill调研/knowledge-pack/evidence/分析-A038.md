## summary

S038 五源合并（D014 评测基准家族与可靠性补充）：① **DeepResearchEval**（arXiv:2601.09688，2026-01-14，cs.CL，Yibo Wang 等 10 人）——自动化深度调研任务构建+agentic 评估框架：任务侧 persona-driven 管线生成锚定多样化用户画像的真实复杂任务，经 Task Qualification + Search Necessity 两级过滤只保留需多源证据整合与外部检索的任务；评估侧 Adaptive Point-wise Quality Evaluation（按任务动态推导评估维度/标准/权重）+ Active Fact-Checking（网络搜索自动验证报告陈述，citation 缺失时可继续验证）。② **OpenAI Agents SDK**（MIT，28,376 stars，2025-03-11 创建）——轻量多 agent 工作流框架，provider-agnostic（Responses/Chat Completions + 100+ LLM），核心概念含 Sandbox agents（容器长时程执行）/Handoffs/Tracing；README 未提及 Swarm。③ **Microsoft Agent Framework**（MIT，12,588 stars，2025-04-28 创建）——生产级 .NET+Python 多 agent 框架，图式工作流（sequential/concurrent/handoff/group + checkpointing/streaming/HITL/time-travel），README 明确提供 AutoGen 与 Semantic Kernel 迁移指南。④ **DeerFlow**（bytedance/deer-flow，MIT，79,245 stars，官网 deerflow.tech）——官方仓库为小写 deer-flow（任务给定 bytedance/DeerFlow 404）；2.0 为 ground-up 完全重写（与 v1 无共享代码），定位从 Deep Research 框架转型为 super agent harness（LangGraph/LangChain 底座），Skills（SKILL.md 渐进加载）/沙箱（Local/Docker/K8s）/隔离子 agent 上下文+summarization 上下文工程/长时记忆（DeerMem 默认 + mem0/OpenViking 可选）/Sub-Agents（优化而非默认）。⑤ **WebThinker**（arXiv:2504.21776，NeurIPS 2025，人大 RUC-NLPIR 团队）——深度研究 agent：Deep Web Explorer + Autonomous Think-Search-and-Draft + 迭代在线 DPO 训练，在 GPQA/GAIA/WebWalkerQA/HLE/Glaive 上声称显著优于现有方法与强专有系统。

**量纲区分硬标注**：DeepResearchEval 与 USTC DRB I/II、FutureSearch DRB 是**相互独立的评测体系**——DRB I 用 RACE/FACT（S010/S020 已采录）、DRB II 用 9430 细粒度二元 rubric（S027 已采录）、DeepResearchEval 用"persona 任务生成 + 动态维度评估 + 主动事实核查"，三者量纲不同，禁止混用对比。

**继任者关系客观陈述**：MAF README 明确提供 AutoGen/Semantic Kernel 迁移指南（继任实证）；Agents SDK README **未提及** Swarm（S030 声称的"Swarm 被取代"需查官方文档/博客确认表述，本 S038 不补充不推断）。

**MisKnow-Agent 对照**：本次抓取的 DeerFlow README 与 WebThinker 摘要均未提及 MisKnow-Agent 评估结果；可靠性对照数据需从 MisKnow-Agent 论文正文获取（线索 LD000003）。
