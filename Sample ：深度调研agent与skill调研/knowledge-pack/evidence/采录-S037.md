## 摘要

OpenManus 是 MetaGPT 团队在 3 小时内开发的开源通用 AI agent 框架，自我定位为"无需邀请码的 Manus 复刻"：MIT 许可、本地部署、用户自带 LLM API key，提供单 agent（main.py）/MCP 工具（run_mcp.py）/多 agent（run_flow.py，官方标注 unstable）三种运行模式，内置 browser-use、computer-use、crawl4ai 等工具集，并衍生出 UIUC+MetaGPT 合作的 OpenManus-RL（RL/GRPO 微调）项目。作为社区项目（非 Manus 官方），它是闭源商业 SaaS Manus 在"开放程度"维度上的直接对照样本。
