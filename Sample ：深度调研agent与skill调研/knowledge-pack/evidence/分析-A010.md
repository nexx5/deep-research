# 分析-A010：DeepResearch Bench 单源分析

## summary

DeepResearch Bench（USTC 团队，arXiv 2506.11763）是"深度调研能力"的公开评测基准：100 个 PhD 级双语研究任务（22 领域），配套 RACE（报告质量，参考+适应性标准）与 FACT（引用可信度，陈述-URL 验证）两套 LLM-as-judge 评估方法，托管于 GitHub（Apache-2.0，805 stars）与 HuggingFace Space 双榜单（legacy Gemini-2.5 45 条目 / GPT-5.5 新榜 10 条目）。该源在生态中的功能定位：为"深度调研"提供可量化、可对比、可提交的评测基座，是各方案官方声称（尤其"领先 DRB 榜单"类表述）的验证参照。本源同时暴露两个生态级事实：评估器从 Gemini-2.5-Pro 切换至 GPT-5.5（LLM-judge 版本敏感、分数绝对值变化），以及存在与 FutureSearch DRB（2506.06287）的同名歧义。

## characteristics

- 评测基准（benchmark）
- LLM-as-judge 评估（GPT-5.5/GPT-5.4-mini/Gemini-2.5 系列）
- 报告质量评估（RACE，reference-based adaptive criteria）
- 引用可信度评估（FACT，statement-URL 支撑验证）
- 公开排行榜（HuggingFace Space 双榜单）
- 提交制评测（email + 自备 key）
- 任务集双语（50 中 / 50 英）、多领域（22）
- 团队背景：中科大 USTC（Agent Research Lab / muset-ai）
- 开源 Apache-2.0（805 stars）
- 评估器版本敏感（2026-05-11 迁移 GPT-5.5）

## opposing_to

按本文内容客观列举可能对立方向（不判定谁对谁错）：

1. **与"方案自评/官方声称"的对立**：若某方案 README 声称"leads DRB RACE leaderboard"，而本榜实测榜首为其他方案，则声称与榜单事实构成对立——本榜即为此类声称的验证参照（榜单含 45+10 条目可对照）。
2. **与 FutureSearch DRB 的同名对立**：两个同名"Deep Research Bench"（任务数/环境/榜单都不同）并存，生态内引用若不区分即产生混淆性对立；两个基准的 RACE 指标同名但不可混用。
3. **评估器版本间对立**：README 明确双榜并列以保证"评估器内可比"，隐含承认跨评估器分数不可直接对比——对"用历史榜单位置宣称领先"的用法构成对立。
4. **与"纯文件方案/无需 web"类方案的对立面**：FACT 方法论以 web 引用支撑验证为核心（依赖 Jina 抓取），对不产出 web 引用链的方案（如本地文件检索型）可能评分口径不适用——本文仅记录 FACT 的 web 依赖事实，不对方案优劣作判断。
5. **与人工采集覆盖面限制的对立**：CL-17 自述无公开 API 方案需人工采集，意味着未覆盖方案可能因采集门槛缺席榜单——榜单完整性受此限制（README 自述）。

## 对生态观察的意义（客观记录）

- 本源定义了一种可操作的"深度调研能力"评估范式（报告质量 + 引用可信度），是生态内方案横向对比的公共标尺之一。
- 榜单为闭源商业方案（Gemini/OpenAI/Perplexity/Grok/Claude 等）与开源/厂商方案（千帆、智谱、cellcog、lunon 等）提供了同一评测池的分数，是"官方声称 vs 独立验证"对照的实证材料。
- 评估器迁移（Gemini-2.5-Pro → GPT-5.5）记录了 LLM-as-judge 基准自身的版本依赖事实。
- 生态内同名基准歧义（本 DRB vs FutureSearch DRB）是引用与对比时必须标注的客观陷阱。
