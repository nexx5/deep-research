# 检查点协议

> 仅当项目规模较大（Phase > 5 或 Task > 15）时启用。中小项目参照 AGENTS.md 的默认检查点协议即可。

---

## 检查点定义

| 代号 | 类型 | 触发条件 | 中断当前工作？ | 需要用户确认？ |
|------|------|----------|---------------|---------------|
| CP-微 | 微型 | 每完成 1 个 Task | 否 | 否 |
| CP-阶段 | 阶段 | 每完成 1 个 Phase | 是 | 是 |
| CP-阻断 | 阻断 | 关键依赖变更 | 是 | 是 |
| CP-完成 | 完成 | 所有 Phase 完成 | 是 | 是 |

## CP-阶段 协议

1. 汇总该 Phase 所有产出物
2. 检查是否有未完成的 Task 及其原因
3. 生成 Phase 摘要（含遗留问题）
4. 通知用户等待确认
5. 用户确认后，更新 task_plan.md，进入下一 Phase
