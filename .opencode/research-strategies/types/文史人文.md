# 文史人文

## 定位

目标是理解人物、事件、文本、制度、思想或文化现象的来源、语境、解释传统和争议。当前为最小策略骨架。

## source_strategy

一手史料、档案、古籍/文本、校注本、学术论文、专著、综述、引用链。

## evidence_ranking

一手史料/原始文本 > 权威校注本 > 学术论文/专著 > 学术综述 > 通俗文章。

## extraction_questions

- 来源是谁、何时、为何产生？
- 是否一手？版本和语境是什么？
- 它能证明什么，不能证明什么？
- 学术解释传统和争议是什么？

## synthesis_dimensions

史料层级、语境、解释传统、争议、互证、边界。

## knowledge_schema_seed

source / text / person / event / context / interpretation / claim / evidence / school / dispute

## saturation_rules

一手与二手区分清楚；主流解释覆盖；关键争议双方有证据；不过度外推。
